**JARVIS** is an autonomous desktop AI assistant featuring voice recognition, biometric authentication, phone integration, and local OS automation.

---

## 🌟 Highlights

- **Voice & Wake Word Pipeline**: Low-latency hotword detection with neural text-to-speech synthesis.
- **Biometric Security**: Face authentication ensuring secure terminal and system command execution.
- **Cross-Platform System Controls**: Window manipulation, media controls, app launching, and automated screen capture.
- **Multi-LLM Routing**: Automatically routes tasks between Groq low-latency reasoning and Gemini multimodal models.
